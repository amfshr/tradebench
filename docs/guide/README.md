# User Guide — reserved

The **Use track** (D21): task-oriented docs for people operating Tradebench — setting up
stream jobs, exploring charts, writing strategies in the DSL, running backtests and bots.
Audience: end users (Dad, brother), who need no knowledge of Java, buffers, or threads.

**Empty by design.** This track is built in the E3/E4 era, when the platform surfaces and
the DSL actually exist. The **DSL / strategy-language reference** lives here (the seat noted
in `docs/product/overview.md`), not in the Field Manual (the Build track — engineering
internals). See decision D21.
