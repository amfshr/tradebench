# Technical design specs

Enduring system/technical design documents — the slowly-evolving layer between design
sessions and code. First expected residents (spawned 2026-09-27): the indicator/predicate
**vocabulary catalogue v0** (E3-T1), later the DSL grammar spec.

Distinct from:

- `docs/design-sessions/` — dated *answered records* of how a design got decided (the
  calibration truth; they don't evolve).
- `/design` (repo root) — UX/page designs and wireframes for the web surfaces.

Specs here trace their rulings to session records and `docs/decisions.md` — a spec asserts
*what is*, the records hold *why*.
